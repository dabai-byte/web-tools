# 网页产品集合

免费在线工具，纯前端实现，无需后端服务器。

## 产品列表

### 1. PDF工具箱 (`/pdf-tools/`)
- PDF合并
- PDF压缩
- PDF拆分

### 2. 随机工具箱 (`/random-tools/`)
- 随机数生成
- 随机密码
- 随机名字
- 随机选择器
- 抛硬币
- 掷骰子

### 3. 图片工具箱 (`/image-tools/`)
- 图片压缩
- 格式转换
- 调整大小

## 技术栈

- 纯 HTML + CSS + JavaScript
- Tailwind CSS (CDN)
- pdf-lib (PDF处理)
- Canvas API (图片处理)

## 部署

### Vercel
```bash
vercel deploy
```

### Netlify
```bash
netlify deploy --prod
```

### GitHub Pages
推送到 GitHub，在 Settings > Pages 中启用。

## 变现策略

1. **Google AdSense** - 页面内广告
2. **推荐链接** - 推荐相关工具/服务
3. **高级功能** - 批量处理、云端存储（需后端）
